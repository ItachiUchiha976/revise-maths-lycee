Terminale spécialité maths (programme 2019) • Propriétés algébriques • Équations & inéquations • Dérivée de eu • Limites & croissances comparées • Étude de fonctions • Modélisation

Comment ça marche : tu écris ta réponse dans la case (ou tu choisis dans la liste), tu cliques sur « Vérifier », et tu vois tout de suite si c'est bon. Le corrigé détaillé pas à pas se déplie pour chaque exercice. Réflexe n°1 du chapitre : ex > 0 pour tout réel x — l'exponentielle ne s'annule jamais et ne change jamais de signe. C'est ce qui permet, dans presque toutes les études de fonction, de simplifier le signe d'un produit.

Ces exos, c'est l'entraînement. Le cours complet, c'est la formation Terminale.

Ici tu t'entraînes : 10 exercices auto-corrigés, des propriétés de base jusqu'à l'étude de fonction type BAC. C'est volontairement de l'entraînement, pas un cours.

Dans la formation Terminale spé maths, tu trouves ce qui manque autour :

  • Le cours pas à pas, module par module, sur tout le programme ;
  • Les fiches méthode : quel réflexe déclencher devant une équation, une limite indéterminée ou une étude de signe ;
  • Les vidéos premium : les 5 pièges classiques + 2 corrections d'annales par module ;
  • Les contrôles notés et les sujets type BAC, avec correction détaillée.

L'épreuve de spécialité maths compte pour le BAC et ta note remonte dans Parcoursup : l'exponentielle tombe presque chaque année, seule ou combinée au logarithme.
